# Health and Wellness Student Organization

## Description
This project is a comprehensive website designed for a student organization focused on "Health and Wellness." It serves as a hub for students to access information, resources, and programs related to physical and mental well-being. This project was developed as part of the Semester 2 curriculum for the FDD course.

## Project Structure
The codebase is organized into the following directories:
- **HTML/**: Contains the structure of the website, including:
    - `about.html`, `contact.html`, and `becomeMember.html` for organizational information.
    - `HealthTopic&Awareness/`: Detailed pages on addiction awareness, mental health, nutrition, physical health, sleep hygiene, and stress management.
    - `Program,Events&Activities/`: Information on active challenges (e.g., Step Challenge), fitness routines, meditation programs, upcoming events (e.g., Blood Donation Drive), and yoga sessions.
    - `resources&Support.html`: A centralized page for accessing wellness tools.
- **CSS/**: Contains the styling for all pages, with a dedicated folder for specific programs and activities to ensure a consistent and responsive UI.
- **JavaScript/**: Implements interactive elements, including form handling for contact, dynamic header/footer loading, and a scroll-to-top feature.
- **Assests/**: 
    - `Images/`: A vast collection of SVG icons and JPG/PNG images related to health and wellness.
    - `DownloadResources/`: PDF guides including meal plans, workout routines, habit trackers, and stress management handbooks.

## Key Features
- **Educational Content**: In-depth guides on various health topics.
- **Interactive Programs**: Schedules and guides for yoga, meditation, and fitness.
- **Resource Library**: Downloadable PDFs for practical health tracking and planning.
- **Member Engagement**: "Become a Member" and "Contact Us" sections to encourage student participation.
- **Responsive Design**: Custom CSS tailored for various wellness-related content sections.

## Technologies Used
- HTML5
